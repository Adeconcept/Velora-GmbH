# Company Profile

## Organization
Velora Commerce GmbH is a fictional 60-person Berlin e-commerce SaaS company.

---


## Business Mission
Provide a reliable online-commerce platform that enables European retail customers to manage storefronts, orders, and customer support.

---


## Critical Business Services
1. Customer authentication and storefront access
2. Checkout and order processing
3. Customer support
4. Software development and deployment
5. Employee productivity and payroll

---


## Technology Summary
The environment uses Microsoft 365, Microsoft Entra ID, Windows 11 endpoints, GitHub, AWS, Ubuntu, Amazon RDS, Amazon S3, CloudTrail, and hosted Splunk.

---


## Data Summary
The company handles customer personal data, order records, payment references, support tickets, employee records, source code, secrets, and security logs.

---


## Security Team Context
Security responsibility is shared by a small IT team. No dedicated security department exists.

---

## Scenario Status
All company, employee, asset, vendor, and risk information is fictional and created for portfolio learning.
