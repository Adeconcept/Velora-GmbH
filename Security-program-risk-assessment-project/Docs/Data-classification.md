# Use this policy:

| Classification | Meaning | Examples | Minimum handling expectation |
|----------------|---------|----------|------------------------------|
| Public | Approved for public release | Marketing pages, public job listings | Integrity protection and approved publishing |
| Internal | Routine business information | Internal procedures, meeting notes | Authenticated employee access |
| Confidential | Harmful if disclosed | Support tickets, source code, internal logs | Least privilege, encryption, logging |
| Restricted | Severe legal, financial, or personal impact if disclosed | Customer records, payroll, credentials, secrets | Strict need-to-know, encryption, MFA, monitoring, retention control |

> The labels are a fictional internal scheme. They are not a legal determination. Personal-data obligations must still be assessed separately.
