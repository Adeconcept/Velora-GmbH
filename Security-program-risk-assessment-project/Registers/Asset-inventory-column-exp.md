# Column explanations

| Column | What to enter |
|-----------|-------------|
| Asset_ID | Stable ID such as AST-001 |
| Asset_Name | Clear system, service, device group, data store, or vendor name |
| Asset_Type | Application, database, endpoint, server, identity, SaaS, log store, network service, or data store |
| Business_Owner | Role accountable for business use |
| Technical_Owner | Role responsible for operation |
| Purpose | Why the company needs the asset |
| Location | AWS region, SaaS, office, or remote workforce |
| Data_Classification | Public, Internal, Confidential, or Restricted |
| Business_Criticality | Low, Medium, High, or Critical |
| Internet_Exposed | Yes, No, or Indirectly |
| RTO_Hours | Maximum desired outage before service should be restored |
| RPO_Hours | Maximum acceptable data-loss window |
| Status | Active, Planned, or Retired |
| Evidence_Basis | Simulated company dossier, observed lab, or assumption |
